完整硬件参数补充（突破全局限制）
按应用模式下同步覆盖 device / name / board / platform / hardware / SoC / ro.boot.serialno，避免“机型与芯片矛盾”。
GPU / OpenGL 渲染器伪装
拦截进程内 glGetString 与 eglGetProcAddress，伪装 GL_VENDOR / GL_RENDERER / GL_VERSION。
Wi-Fi / 网卡 MAC 地址伪装
拦截 getifaddrs 与 ioctl(SIOCGIFHWADDR)，替换目标应用读到的网卡硬件地址。
Widevine DRM ID 伪装
拦截 MediaDrm.getPropertyByteArray("deviceUniqueId")，返回独立的 32 字节设备指纹。
内核 uname 信息伪装
拦截目标应用调用 uname() 返回的内核版本，隐藏自定义编译内核特征。
内核 boot_id 伪装 (/proc/sys/kernel/random/boot_id)
防止同一次开机内连续切号或重开应用被同一 boot_id 关联。
超级伪装模式 · 全维度新机参数

仅作用于“设备身份 → 超级伪装模式”当前选中的新机与独立超级目标列表：接管 CPU 拓扑频率、RAM/存储、Vulkan、SoC、电池、基带与环境隐匿。

当前未启用超级伪装机型。请前往“设备身份 → 超级伪装模式”生成或开启一套超级新机后再调整，或在下方预览配置。
超级伪装新机引擎 当前：未开启
点击一键套用将同步当前超级机型的 CPU、内存、存储、Vulkan、GPU 与基带全套参数。
一键美区模式 (US Region) 美区已生效
一键切换目标应用内的美国本土环境：强制 `en-US` 系统语言与资源、美区时区、美国运营商 (`310260`/`310410`/`311480`)、Wi-Fi 国家码 (`US`) 与美区 GPS 坐标；关闭开关即无缝还原原配置。
CPU 处理器拓扑与频率伪装
虚拟 `/proc/cpuinfo`、`/sys/devices/system/cpu/cpu*/cpufreq/*`、ARM `midr_el1` 与 `sysconf` 核心数。
运行内存 RAM 与 UFS 存储容量伪装
拦截 `/proc/meminfo`、`sysinfo()` 与 `statfs`/`statvfs`（接管 AIDA64 与 `StatFs` 内存/磁盘总容量）。
Vulkan 硬件加速驱动伪装
拦截 `vkGetInstanceProcAddr` / `vkGetPhysicalDeviceProperties*`，同步修改 Vulkan 设备名、VendorID、DeviceID 与 UUID。
SoC 硬件节点伪装 (/sys/devices/soc0)
虚拟 `family` / `machine` / `chip_name` / `soc_id` / `serial_number`，消除真实芯片平台残留。
电池设计容量与开机时间 (/sys/class/power_supply + /proc/uptime)
改写电池设计容量 (`mAh`) 与当前开机持续运行时间 (`uptime`)。
运营商 / 基带 / SIM / 虚拟 IMEI
覆盖 `gsm.operator.*`、`gsm.sim.operator.*`、`gsm.version.baseband`（同步 `Build.getRadioVersion()`）及 IMEI 属性。
构建主机与时区/语言 (`Build.HOST` / `TimeZone` / `Locale`)
覆盖 `Build.HOST` / `USER` / `SKU`、`ro.build.*` 与进程内 `TimeZone` / `Locale`。
超级新机硬件标识与主板代号 (ro.product.* / SoC / Boot)
同步改写超级目标进程读到的设备代号、主板平台、SoC 型号、Boot 序列号，并抑制宿主机 MIUI / 第三方 ROM 残留属性。
GPU OpenGL 渲染器伪装
拦截进程内 `glGetString`，与上方 Vulkan 参数协同伪装 `GL_VENDOR` / `GL_RENDERER` / `GL_VERSION` 及驱动提示。
网卡 MAC / Widevine DRM / 内核 uname 与 boot_id
为超级新机进程提供独立的网卡硬件地址、Widevine ID、内核 `uname` 与虚拟 `boot_id`。
系统纯净态属性 (Bootloader 锁定与非调试)
在目标进程内强制返回 `verifiedbootstate=green`、`flash.locked=1`、`ro.debuggable=0`、`ro.secure=1`、`sys.usb.state=none` 并净化 `/proc/cmdline`。
进程环境隐匿 (`/proc/self/maps` 与 `mounts` 过滤)
过滤目标进程读取 `/proc/self/maps` 与 `/proc/mounts` 时暴露的 Zygisk / `/data/adb` / 模块特征行。
Android ID (SSAID)

按包名修改系统 settings_ssaid.xml 中的 Android ID。保存后需重启手机生效。

需为 16 位小写十六进制字符（0–9，a–f）。
